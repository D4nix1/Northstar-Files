# Northstar Files 0.1.0 — experimental

This is an early public test build for Windows. It may contain bugs or incomplete features. Back up important files before testing file operations.

## Included

- `Northstar-Files-Setup.exe`: installs under Program Files, adds a Start menu shortcut, and offers a Desktop shortcut.
- `Northstar-Files.exe`: portable build for evaluation.

## Feedback

Please report bugs and suggestions in GitHub Issues. Include your Windows version, steps to reproduce, expected behavior, and what happened. Do not attach files or logs containing personal information.

## Known limits

The app is experimental. Large transfer queue controls, universal previews, NTFS permission editing, and file version history are not implemented. The uninstaller tool launches each application's registered uninstaller and cannot guarantee removal of every leftover file.

SHA-256 checksums for both downloads are attached as SHA256SUMS.txt.
